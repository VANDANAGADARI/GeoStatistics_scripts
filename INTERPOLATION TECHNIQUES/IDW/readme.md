# Inverse Distance Weighting (IDW) Interpolation
Deterministic spatial interpolation technique used to estimate the values of unknown points based on the values of known scattered points.

Principle: the value of an unsampled point is a distance-weighted average of the known data points surrounding it.

Tobler’s First Law of Geography, which states: "Everything is related to everything else, but near things are more related than distant things."
Points that are geographically closer to the target point carry a higher weight (influence) in determining the estimated value than points further away.

Used for: Dense Data Points, Continuous Phenomenon,Local Influence Dominates
Limitation: Sparse or Clustered Data, Topographical Barrriers, Extreme Outliers 

Key Parameters:
Power ($p$): Controls the significance of surrounding points

Search Radius/Point Count ($n$): Determines how many known points are factored into a single calculation. 

# Python Libraries:
1.geopandas:
Reads the input shapefile (.shp), manages the coordinate reference system (CRS), and extracts the X, Y coordinates and the $Z$ attribute values from the point geometries.

2.numpy: 
Handles the heavy mathematical lifting. It creates the 2D spatial grid (the target pixels) and performs the vectorized IDW matrix calculations.

3.scipy
A spatial indexing algorithm used to rapidly calculate distances between the thousands of grid pixels and the known sample points. 
It prevents system memory crashes by only calculating distances to the nearest $k$ points rather than every point in the dataset.

4.rasterio:
Takes the raw 2D mathematical array generated by NumPy and writes it out as a spatial GeoTIFF file, attaching the physical bounding box (transform) and the CRS.
